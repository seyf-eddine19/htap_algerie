{% translate "Comprendre la maladie" %}

{% translate "Qu'est-ce que l'Hypertension Artérielle Pulmonaire ?" %}

{% translate "L’Hypertension Artérielle Pulmonaire (HTAP) est une maladie rare qui se caractérise par une augmentation anormale de la pression dans les artères pulmonaires. Cette augmentation de pression peut entraîner une surcharge de travail pour le cœur, en particulier pour le ventricule droit." %}

{% translate "L’HTAP nécessite une évaluation médicale spécialisée afin d’en confirmer le diagnostic, d’en rechercher la cause et de déterminer une prise en charge adaptée à chaque personne." %}

{% translate "Essoufflement" %}

{% translate "Un essoufflement, notamment lors des efforts, peut faire partie des signes de la maladie." %}

{% translate "Fatigue persistante" %}

{% translate "Une fatigue inhabituelle peut également être observée." %}

{% translate "Diagnostic spécialisé" %}

{% translate "Le diagnostic repose sur plusieurs examens médicaux et peut nécessiter l'avis d'un centre spécialisé." %}
